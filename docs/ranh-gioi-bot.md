# Ranh giới bot — được / không được gửi

## Bạn có thể đưa

- Địa chỉ ví **public**
- API sàn **trade-only** (trong `.env` máy bạn)
- Telegram bot token + chat id
- RPC URL

## Không bao giờ gửi cho tool / agent / “admin”

- Seed 12/24 từ
- Private key
- Mật khẩu email / sàn
- Mã 2FA / backup 2FA
- API có quyền **Withdraw**

## Bot không làm

- Nhân bản nhiều ví/acc
- Auto-click game, né ban
- Copy-trade video YouTube
- Tự ký mọi contract dự án mới
- Sniper / sandwich / pump

Nếu ai đó nhân danh repo này xin seed — đó là lừa đảo.
