# Airdrop và game nhận coin

## Airdrop

Làm ít việc **thật** trên một ví: dùng sản phẩm, giữ tx. Points có thể về 0 nếu dự án hủy mùa.

Bot: danh sách curated + trạng thái (theo dõi / đến hạn claim). Claim: **bạn** mở site chính thức.

## Game

1. Tab Game: xem đề xuất, rủi ro, có API không.
2. Bấm chọn. Đọc playbook.
3. Có API official → bật module `Game API`, daily cap (mặc định 1).
4. Không API → làm tay theo checklist; bot nhắc.

Không làm: auto-click, script “giống người cho khỏi ban”, nhiều acc.

## Khi nào dừng

Approve lạ, phí vô lý, yêu cầu seed, hứa lãi cố định, phải tuyển F1 hàng loạt.
