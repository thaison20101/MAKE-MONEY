# 11. NFT và game on-chain

## Ý chính

NFT là token chứng minh mục trên chuỗi. Game có thể thưởng coin/NFT nếu bạn chơi. **Phần lớn game-airdrop không bền**; botting dễ bị ban.

## Giải thích

Play-to-reward / play-to-airdrop: dự án cho điểm khi làm nhiệm vụ. Đến mùa TGE có thể phát token — hoặc không, hoặc token rớt 90%.

Tool này:

- Tìm và đề xuất game + playbook hợp lệ
- Auto **chỉ** khi có API/SDK chính thức, 1 tài khoản, daily cap
- Không auto-click Telegram, không farm nhiều acc

## Thử ngay

Vào tab **Game** trên app, đọc 1 playbook mẫu. Chưa kết nối ví vào game lạ.

## Sai lầm hay gặp

- Mua “tool farm 100 acc”.
- Mint NFT game bằng ví đang giữ tiết kiệm.
