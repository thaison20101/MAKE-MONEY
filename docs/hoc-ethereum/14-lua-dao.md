# 14. Lừa đảo thường gặp

## Ý chính

Kẻ lừa muốn **chìa** hoặc **chữ ký** của bạn. Không cần “hack blockchain”.

## Các kiểu

- Hỗ trợ giả (Telegram/Discord) xin seed để “đồng bộ”.
- Airdrop / mint domain giả (`unlswap.com`).
- Drain signature: “ký để verify ví”.
- Token dust: gửi rác, bạn approve để “bán”.
- Giả Ledger / extension trên Google Ads.
- Việc “admin tool” bảo bạn dán API có quyền Withdraw.

## Thử ngay

Viết ra giấy: “Không ai được xin seed”. Dán lên màn hình.

## Sai lầm hay gặp

- Share screen ví khi seed đang hiện.
- Tắt whitelist rút “cho tiện”.
