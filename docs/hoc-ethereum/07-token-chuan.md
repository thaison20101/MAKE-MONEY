# 07. ERC-20, NFT, Etherscan

## Ý chính

**ERC-20** là chuẩn token chuyển được như xu. **ERC-721 / 1155** là NFT (mỗi món hoặc mỗi loại có id). **Etherscan** là kính lúp xem chuỗi Ethereum.

## Giải thích

Token giả có thể trùng tên “USDT” nhưng **địa chỉ hợp đồng khác**. Luôn đối chiếu contract trên trang dự án chính thức hoặc CoinGecko.

NFT không tự chứng minh bạn sở hữu bản quyền ngoài đời. Ảnh có thể bị copy. Game NFT có thể tắt server.

## Thử ngay

Vào Etherscan → Token → tìm USDT. Copy **contract**, so với địa chỉ trong ví khi nhận chuyển.

## Sai lầm hay gặp

- Thêm token lạ theo link chat → thấy “số dư khủng” nhưng không bán được (honeypot / dust).
- Mua NFT OpenSea giả domain.
